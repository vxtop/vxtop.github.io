See what your computer is doing, not just what it holds.Mira lo que tu equipo está haciendo, no solo lo que guarda.

vxtop is a read-only 3D observatory. Every folder is a cube of 27 cells, every open program another cube, and whatever is being used right now lights up and moves — by you, by other programs or by an AI agent like Claude Code.vxtop es un observatorio 3D de solo lectura. Cada carpeta es un cubo de 27 celdas, cada programa abierto otro cubo, y lo que se está usando ahora mismo se enciende y se mueve: lo que haces tú, lo que hacen otros programas o lo que hace un agente de IA como Claude Code.

Get startedEmpezar

You need Node.js 18.15+ and Chrome or Edge. Windows is the most complete platform; Linux works.Necesitas Node.js 18.15 o superior y Chrome o Edge. Windows es la plataforma más completa; Linux funciona.

# live view of the whole machinevista en vivo de todo el equipo
npx github:vxtop/vxtop

# a project and its subfoldersun proyecto y sus subcarpetas
npx github:vxtop/vxtop ./my-project --expand

# try it without showing your filespruébalo sin enseñar tus archivos
git clone https://github.com/vxtop/vxtop && cd vxtop
npm run demo

On Windows, double-click vxtop.vbs for a console-free app window.En Windows, doble clic en vxtop.vbs: ventana propia y sin consola.

It only looksSolo mira

vxtop never creates, changes or deletes anything it observes, and never acts on processes or the system.vxtop nunca crea, cambia ni borra nada de lo que observa y nunca actúa sobre procesos ni sobre el sistema.

Local onlySolo en tu equipo

Listens on 127.0.0.1, every call carries a session token, nothing is sent anywhere.Escucha en 127.0.0.1, cada consulta lleva un token de sesión y nada sale de tu equipo.

Your screen stays yoursTu pantalla es tuya

Live images of your windows are off until you allow them.Las imágenes en vivo de tus ventanas están apagadas hasta que las permites.

Least privilegeMínimos permisos

Runs without administrator rights; more data only if you ask, and still read-only.Funciona sin administrador; más datos solo si lo pides, y sigue siendo de solo lectura.
